# Being Marketive Marketing Skill

A beginner-friendly Agent Skill for creating practical marketing playbooks, SEO plans, and social media content for **Being Marketive**.

**Tagline:** Marketing Playbooks for Every Industry.  
**Supporting phrase:** Learn. Apply. Grow.

## What's included
- `SKILL.md` — core skill instructions (required)
- `templates/content-calendar.md` — reusable content calendar template
- `templates/seo-content-brief.md` — reusable SEO brief template
- `references/brand-guide.md` — concise brand reference

## Use
This folder follows the open Agent Skills format. Compatible agents need to support Agent Skills and be configured to load this skill; putting it on GitHub alone does not automatically activate it inside every ChatGPT conversation.

## Install/use notes
1. Keep the folder name `being-marketive-marketing` to match the skill name in `SKILL.md`.
2. Upload the folder and files to a GitHub repository.
3. To use it, follow the skill-loading instructions for your specific compatible AI agent/product.

## Suggested repository
`being-marketive-marketing-skill`

## First test prompt
> Create a 30-day Instagram content calendar for Being Marketive for beginner digital marketers in India. Include content pillars, hooks, format, caption angle, CTA, and KPI. Keep the tone practical and use the brand guide.
